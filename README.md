# AnimePulse

AnimePulse est un site de suivi d'animes en français. Il permet :

- de parcourir une collection d'animes
- de rechercher un anime par titre ou genre
- de noter chaque anime de 1 à 10
- d'ajouter des titres à sa watchlist
- de consulter les prochaines sorties / saisons à venir
- de garder les données localement dans le navigateur

## Démarrage

Ouvrez simplement le fichier `index.html` dans votre navigateur.

## Structure du projet

- `index.html` : structure principale de la page
- `style.css` : styles de l'interface
- `script.js` : logique de recherche, favoris, notes et sorties

## Exemple d'utilisation

1. Recherchez un anime dans la barre de recherche.
2. Ajoutez-le à votre liste en cliquant sur le bouton "♥" ou "+ Liste".
3. Attribuez une note via le sélecteur de note.
4. Consultez les sorties prévues dans la section "À venir".
